Website လှလှနဲ့ project စာရင်းရှည်ကို မြင်ရတာ အားရစရာပါ။ ဒါပေမယ့် မိမိလုပ်ငန်းအတွက် အလုပ်အပ်နိုင်မလား ဆုံးဖြတ်ရာမှာ ဘယ်လိုပူးပေါင်းလုပ်မလဲဆိုတာပါ သိထားရပါမယ်။

လုပ်ငန်းနယ်ပယ်တူတဲ့ project လုပ်ဖူးခြင်းက ကောင်းတဲ့အစဖြစ်ပါတယ်။ တူညီတဲ့အမည်ရှိတဲ့ POS နှစ်ခုတောင် အကြွေး၊ ပြန်အမ်းနဲ့ ဆိုင်ခွဲစီမံပုံ မတူနိုင်လို့ မိမိအလုပ်စဉ်နဲ့ ပြန်စစ်ရပါမယ်။

### ပထမဆုံးဆွေးနွေးချိန်မှာ မေးပါ

- လိုအပ်ချက်ကို ဘယ်သူက နားထောင်ပြီး စာနဲ့ ပြန်အတည်ပြုပေးမလဲ။
- ဘယ်အချိန်မှာ အလုပ်လုပ်တဲ့ demo ကို ကြည့်ရမလဲ။
- အမှားတွေ့ရင် ဘယ်နေရာကို တင်ပြီး ဘယ်သူက တာဝန်ယူမလဲ။
- ဝန်ထမ်းတွေကို စမ်းသုံးခွင့်နဲ့ training ပေးမလား။
- Source code၊ domain၊ server account နဲ့ data ကို ဘယ်သူပိုင်မလဲ။
- ဆက်မလုပ်ဖြစ်တော့ရင် data နဲ့ documentation ဘယ်လိုပြန်ရမလဲ။

အဖြေကို “စိတ်ချပါ၊ အကုန်လုပ်ပေးမယ်” ဆိုတာနဲ့ မရပ်ပါနဲ့။ အပ်နှံမယ့်အလုပ်အတိုင်းအတာ၊ ပေးအပ်မယ့်ဖိုင်၊ ဆက်သွယ်ရမယ့်သူနဲ့ စမ်းသပ်ချိန်ကို quotation ထဲမှာ မြင်ရဖို့ လိုပါတယ်။

**ဒီနေ့လုပ်ကြည့်ရန် —** စဉ်းစားထားတဲ့ အဖွဲ့တွေကို တူညီတဲ့ လုပ်ငန်းအကျဉ်းနဲ့ တူညီတဲ့မေးခွန်း ပေးပါ။ ဒါမှ စျေးနှုန်းတစ်ခုတည်းထက် လုပ်ဆောင်ပုံနဲ့ တာဝန်ယူမှုကို တန်းတူနှိုင်းယှဉ်နိုင်ပါမယ်။
